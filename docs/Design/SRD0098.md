## Description
  
Specify NULL or NOT NULL explicitly for table columns.
  
## Summary
  
Specify whether table columns are nullable.
  
### Examples
  
```sql
CREATE TABLE dbo.ExplicitNullability
(
    RequiredColumn INT NOT NULL,
    OptionalColumn INT NULL,
    UnspecifiedColumn INT,
    ComputedColumn AS (1 + 1),
    IdentityColumn INT IDENTITY(1, 1),
    SparseColumn INT SPARSE,
    TablePrimaryKeyColumn INT,
    CONSTRAINT PK_ExplicitNullability PRIMARY KEY CLUSTERED (TablePrimaryKeyColumn)
);

-- SRD0098
```
```sql
CREATE TABLE dbo.InlinePrimaryKeyNullability

);

-- SRD0098
```
  
### Remarks
  
Column nullability defaults can depend on the ANSI_NULL_DFLT settings. Specify NULL or
NOT NULL explicitly to make the intended column definition clear and consistent.
